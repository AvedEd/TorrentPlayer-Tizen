# TorrentPlayer & Lampa Integration Guide

**TorrentPlayer** — это нативный, ультра-компактный и защищенный от сбоев видеоплеер для телевизоров **Samsung Smart TV (OS Tizen)**, разработанный специально для потокового воспроизведения торрентов через сервер **TorServe**.

---

## 🚀 Что умеет этот плеер?

1. **Потоковый запуск (Streaming):** Воспроизведение тяжелых торрент-файлов «на лету» без предварительного скачивания в память ТВ.
2. **Умное автопереподключение (Auto Reconnect):** При кратковременном обрыве связи с TorServe или Wi-Fi плеер делает до 5 скрытых попыток восстановить поток, продолжая показ точно с той же миллисекунды.
3. **Продвинутый кэш:** Прямо во время просмотра в нижнем меню можно жестко выставить размер буфера предзагрузки (Авто, 100 МБ, 200 МБ, 500 МБ).
4. **Статус TorServe (Кнопка ВВЕРХ):** Панель мониторинга в правом верхнем углу экрана. Показывает реальную скорость скачивания и объем заполненного буфера в мегабайтах. Закрывается кнопкой `BACK`.
5. **Нижнее Мега-Меню (Кнопка ВНИЗ):** Всплывающий горизонтальный интерфейс для быстрого переключения аудиодорожек (озвучек), субтитров и управления кэшем без остановки видео.
6. **Правая шторка серий:** Интегрированный список эпизодов для многосерийных раздач с удобным выбором и автопереключением.
7. **Память позиций:** Автоматическое запоминание секунды, на которой вы остановили просмотр.

## 🛠️ Инструкция по сборке .wgt файла на компьютере

Так как мы используем классический автономный метод установки без зависимости от сторонних серверов загрузки, проект нужно упаковать в виджет:

1. Зайдите в свой репозиторий GitHub на ПК, нажмите зеленую кнопку **Code** -> **Download ZIP**.
2. Распакуйте скачанный архив.
3. Перейдите в распакованную папку. **Важно:** в корне этой папки должны сразу лежать файлы `index.html`, `config.xml` и папки `js`, `css`.
4. Выделите **все внутренние файлы и папки** (но не саму родительскую папку!).
5. Кликните правой кнопкой мыши -> **Отправить** -> **Сжатая ZIP-папка** (или используйте 7-Zip/WinRAR для создания `.zip` архива).
6. Переименуйте получившийся файл: замените расширение `.zip` на **`.wgt`** (например, `TorrentPlayer.wgt`). Подтвердите изменение расширения в системе.

## 📺 Инструкция по установке на Samsung Smart TV

### Способ 1: С флешки (Для моделей до 2015-2016 гг.)
1. Форматируйте флешку в FAT32.
2. Создайте в корне флешки папку с именем `userwidget`.
3. Скопируйте ваш файл `TorrentPlayer.wgt` внутрь папки `userwidget`.
4. Вставьте флешку в работающий телевизор. Установка начнется автоматически.

### Способ 2: Через Tizen Studio / Tizen App Installer (Для моделей 2016–2026+)
1. На телевизоре зайдите в Smart Hub -> приложения (`Apps`).
2. Нажмите на пульте цифры `1, 2, 3, 4, 5`, чтобы открыть окно **Developer Mode** (Режим разработчика).
3. Переключите ползунок в положение **ON**, введите IP-адрес вашего компьютера и перезагрузите ТВ (зажмите кнопку включения на пульте до перезагрузки).
4. Запустите программу установщик (Tizen Studio или сторонний Tizen App Installer) на компьютере.
5. Подключитесь по IP-адресу телевизора и отправьте файл `TorrentPlayer.wgt` на установку одной кнопкой.

## 🔗 Интеграция с каталогом Lampa

Наш написанный плагин `lampa-plugin.js` позволяет каталогу Lampa без швов сворачиваться и мгновенно перенаправлять видеопоток в нативный TorrentPlayer.

### Как это работает при просмотре:
1. Вы открываете **Lampa** на телевизоре (при этом TorrentPlayer должен быть запущен в фоне).
2. Находите фильм или сериал, переходите во вкладку **Торренты** (TorServe).
3. Выбираете файл/серию и нажимаете кнопку **Смотреть**.
4. Плагин перехватывает сгенерированную TorServe ссылку, дает команду Lampa закрыть стандартный плеер и мгновенно передает поток методу `window.TorrentApp.playUrl(streamUrl)`.
5. Экран Lampa скрывается, и видео запускается в вашем плеере со всеми фишками управления.

### Как подключить плагин в Lampa:
1. Откройте ваш файл `lampa-plugin.js` на GitHub.
2. Нажмите кнопку **Raw** в верхней панели файла, чтобы получить чистую текстовую ссылку. Она должна начинаться с `https://githubusercontent.com...`. Скопируйте её.
3. Запустите **Lampa** на телевизоре.
4. Перейдите в **Настройки** -> **Плагины** -> **Добавить плагин**.
5. Вставьте скопированную Raw-ссылку в поле ввода и нажмите **ОК**.
6. Перезапустите приложение Lampa.
7. Перейдите в настройки Lampa -> **Плеер** -> **Тип плеера** и выберите пункт **`TorrentPlayer (WGT)`**.
